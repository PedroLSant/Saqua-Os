# SaquaOS

Sistema de gerenciamento de Ordens de Serviço.

## Sobre o projeto

O SaquaOS foi desenvolvido para facilitar o cadastro, acompanhamento e gerenciamento de ordens de serviço.

## Funcionalidades

- Cadastro de ordens de serviço
- Gerenciamento de clientes
- Cadastro de equipamentos
- Acompanhamento do status das ordens
- Registro de técnicos

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Firebase
